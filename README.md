##9router

Hãy tìm thứ gì đó tốt hơn Claude, ví dụ như hầu hết các thư viện hỗ trợ khác. Claude có vấn đề khá nghiêm trọng về dung lượng bộ nhớ, nó ngốn khoảng 30.000 token chỉ riêng cho các lời nhắc hệ thống và có thể khiến các mô hình cục bộ hoạt động kém hiệu quả - thậm chí chính các mô hình của họ cũng chạy tệ hơn trên Claude Code so với một thứ gì đó như OpenCode.

- Tôi khuyên bạn nên dùng Pi hoặc Hermes.

- Nếu nó được phân giải thông qua DNS, bạn luôn có thể cập nhật tệp hosts của mình...

- Cách dễ nhất để làm điều này là sử dụng 9router. Tôi không nhớ liệu nó có tự động cấu hình như hầu hết các phần mềm khác hay không, nhưng nó sẽ hướng dẫn bạn cách làm. Tôi đã từng làm rồi. Bạn có thể thiết lập để chuyển sang API cục bộ hoặc API khác khi lượng sử dụng của bạn giảm xuống. Tôi nghĩ Omniroute cũng có thể làm điều tương tự.
